# Codex 风格工作区实施计划

日期：2026-10-08。目标：为现有三 Agent 工作流增加轻量、可运行的编码工作区，并使用用户提供的本地 DeepSeek 配置验证真实调用。

设计选择：继续使用 Streamlit 可快速换布局，但任务进度与三栏工作区受框架限制；独立前端 + FastAPI 可直接控制布局与交互，复用已安装依赖；React 构建链会增加本次作业的部署成本。因此采用原生 HTML/CSS/JS + FastAPI，保留现有 CLI 与 Streamlit。

界面：左侧项目/任务历史、主区任务对话和 Agent 执行卡片、右侧代码/差异/问题/日志；浅色桌面主题和深色主题切换，窄屏折叠。空状态提供示例快捷入口，真实/演示模式明确区分。模型配置只显示是否配置和模型名，密钥只保存在 .env。

API：任务提交后后台线程顺序执行，返回运行 ID；前端轮询持久化状态，支持历史查看和失败恢复。管理器拒绝同运行重复启动；输出使用 textContent，避免源码中的 HTML 注入。源码/需求设大小上限，最多同时运行两项任务。
