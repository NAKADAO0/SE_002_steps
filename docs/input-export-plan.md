# 自然语言、文件输入与最终代码导出

用户授权扩展现有工作区。沿用三 Agent 核心，不新增模型路由请求。自然语言仅用于代码生成、审查修复与只审查；明确“只审查/不要修改”等短语禁用修复。上传源码优先走已有代码流程，文件无需求时生成默认审查修复需求。

使用独立上传 API，读取不超过 100KB 的 Python 文件，不写入源文件目录，不执行文件。支持 UTF-8/BOM 及 Python 编码声明。接口拒绝路径名、非 .py、空文件和非法编码。保存原始文件名至检查点与消息。

最终导出 API 仅允许 completed，返回 UTF-8 Python 附件；中间/失败/待人工处理状态不得伪装为最终代码。工作区显示上传文件标签及清晰导出按钮。
